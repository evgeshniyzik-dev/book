# BookSwap — скелет доски объявлений о книгах

Kotlin + Jetpack Compose + Material 3. Данные хранятся в памяти (демо-набор из 9 объявлений).

## Что можно потрогать в приложении

**Нижняя навигация:** Лента · Избранное (со счётчиком-бейджем) · Мои · Настройки

**Лента:**
- поиск по названию, автору и городу
- фильтр по типу: продать / купить / обменять
- раскрывающиеся фильтры: состояние книги, ползунок максимальной цены
- сортировка: новые / дешевле / дороже / по названию
- переключение вида список ↔ сетка
- счётчик найденного, пустое состояние с кнопкой сброса
- сердечко «в избранное» прямо на карточке

**Карточка объявления:** избранное, системный шаринг, разворачивающийся блок контакта

**Создание объявления:** переключение типа (поля меняются под тип), выпадающий список состояния, Switch «торг уместен», валидация обязательных полей

**Мои объявления:** удаление со Snackbar «Отменить»

**Настройки:** тёмная тема, динамические цвета (Android 12+), компактные карточки, показ города, «только с ценой», «скрыть мои объявления», сброс к демо-данным с диалогом подтверждения

## Как получить APK

### Вариант 1 — GitHub Actions (без установки чего-либо)

1. Создайте репозиторий на GitHub и залейте туда содержимое этой папки
2. Сборка запустится автоматически при пуше в `main`; вручную — вкладка **Actions** → **Build APK** → **Run workflow**
3. Когда прогон завершится, откройте его и скачайте артефакт `bookswap-debug-apk`
4. Распакуйте zip, перекиньте `.apk` на телефон, установите (разрешив установку из неизвестных источников)

### Вариант 2 — Android Studio

1. File → Open → выбрать эту папку
2. Дождаться синхронизации Gradle (скачает зависимости)
3. Build → Build Bundle(s)/APK(s) → Build APK(s)
4. APK появится в `app/build/outputs/apk/debug/`

Либо подключить телефон по USB с включённой отладкой и нажать Run — установится напрямую.

### Вариант 3 — командная строка

Нужен установленный Android SDK и переменная `ANDROID_HOME`:

```bash
gradle assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```
